# Deco Admin - 서울 문화행사 데이터 기반 데이트 코스 관리 대시보드

이 프로젝트는 서울시 공공데이터인 '서울시 문화행사 정보'를 분석하여, 커플 데이트 코스 공유 앱 **Deco**의 운영자가 효율적으로 장소를 선별하고 추천할 수 있도록 돕는 관리자용 대시보드입니다.

## 🚀 프로젝트 개요
- **목적**: 데이터 기반의 데이트 장소 후보군 도출 및 추천 태그 관리
- **대상 데이터**: 서울시 문화행사 정보 (약 3,900건)
- **주요 기능**: 
  - EDA 기반 핵심 인사이트 시각화
  - 운영자 전략 가이드 제공
  - 추천 후보 관리 샘플 리스트
  - 향후 앱 연동 로드맵 제시

## 📂 폴더 구조
- `docs/`: 정적 웹 대시보드 소스 (GitHub Pages 배포용)
  - `index.html`: 메인 대시보드 구조
  - `style.css`: 관리자 UI 디자인
  - `app.js`: 추천 리스트 및 인터랙션 로직
  - `images/`: EDA 분석 결과 그래프 이미지
- `data/`: 원본 CSV 데이터
- `report/`: 탐색적 데이터 분석(EDA) 보고서
- `scripts/`: 데이터 분석용 파이썬 스크립트
- `src/`: 프로젝트 소스 코드 베이스

## 🛠 실행 방법
### 1. 웹 대시보드 확인 (로컬)
별도의 서버 설정 없이 `docs/index.html` 파일을 브라우저에서 열면 대시보드를 바로 확인할 수 있습니다.

### 2. 데이터 분석 재실행 (Python)
프로젝트 루트에서 다음 명령어를 통해 분석을 다시 수행할 수 있습니다.
```bash
# uv가 설치되어 있어야 합니다.
uv run python scripts/eda_analysis.py
```

## 🌐 배포 방법 (GitHub Pages)
1. GitHub 저장소의 **Settings**로 이동합니다.
2. **Pages** 메뉴를 선택합니다.
3. **Build and deployment** 섹션의 **Branch** 설정에서 `main` 브래치를 선택하고 폴더를 `/docs`로 설정한 후 **Save**를 클릭합니다.
4. 잠시 후 제공되는 URL을 통해 대시보드에 접속할 수 있습니다.

## 📈 주요 분석 인사이트 요약
- **지역**: 종로구, 중구 등 문화 인프라 밀집 지역 우선 추천
- **요일**: 금/토 시작 행사가 많으므로 주말 코스 중심 기획
- **비용**: 높은 무료 행사 비중을 활용한 '가성비 데이트' 테마 강화
- **키워드**: '전시', '체험', '콘서트' 등 인기 태그 자동화 가능성 확인
