# Deco Admin - 데이터 기반 데이트 코스 운영 관리 대시보드

본 프로젝트는 커플 데이트 코스 공유 플랫폼 **Deco**의 초기 운영 효율화를 위한 **운영자 전용 관리 대시보드(Admin Dashboard)**입니다.

## 📱 서비스 맥락 (Service Context)
**Deco**는 사용자들이 직접 다녀온 데이트 코스를 기록하고 공유하는 앱입니다. 서비스 출시 초기에는 사용자 생성 콘텐츠(UGC)가 부족한 '콜드 스타트(Cold Start)' 문제가 발생합니다. 

**Deco Admin**은 이러한 문제를 해결하기 위해 공공데이터(서울시 문화행사 정보)를 분석하여, 운영자가 **고품질의 추천 장소 후보를 선별**하고 이를 앱의 **초기 추천 콘텐츠로 공급**할 수 있도록 돕는 관제 센터 역할을 합니다.

## 🎯 주요 목표
1. **데이터 기반 후보 선별**: 서울시 3,900여 건의 문화행사 데이터를 분석하여 최적의 데이트 장소 발굴
2. **Deco 앱 연동 구조 설계**: 선별된 데이터를 앱의 홈 화면, 필터, 상세 가이드로 즉시 전환 가능한 구조 구축
3. **태그 및 추천 시스템 관리**: '실내', '가성비', '야간' 등 데이트 특화 태그 시스템 구축

## 🔗 Deco 앱과의 연결 모델
Admin에서 관리되는 데이터는 다음과 같이 유기적으로 Deco 앱 사용자 경험(UX)과 연결됩니다.
- **추천 후보 TOP 리스트** &rarr; Deco 앱 홈 화면의 **[추천 코스]** 영역 노출
- **장소 테마 및 태그** &rarr; Deco 앱의 **[검색 필터/카테고리]** 시스템 연동
- **위치 정보 (위경도)** &rarr; Deco 앱 **[지도 화면]** 내 장소 핀 포인트 및 경로 생성
- **운영자 추천 이유** &rarr; Deco 앱 **[코스 상세 설명]** 가이드 텍스트로 활용

## 📂 폴더 구조
- `docs/`: 정적 웹 대시보드 소스 (GitHub Pages 배포용)
  - `index.html`: 서비스 맥락이 반영된 대시보드 UI
  - `style.css`: 프리미엄 관리자 디자인 테마
  - `app.js`: 추천 데이터 렌더링 로직
  - `data/`: EDA 스크립트가 생성한 추천 후보 JSON/JS 데이터
  - `images/`: EDA 스크립트가 생성한 대시보드 그래프
  - `reference/`: Deco 앱 기획 및 화면 참고 자료
- `data/`: 원본 CSV 데이터
- `report/`: 탐색적 데이터 분석(EDA) 상세 보고서
- `scripts/`: 데이터 전처리, 리포트, 추천 후보 데이터 생성 스크립트

## 🛠 실행 및 확인
- **대시보드 보기**: `docs/index.html` 파일을 브라우저에서 실행
- **CSV로 분석 재실행**: `uv run python scripts/eda_analysis.py --source csv`
- **Open API로 분석 재실행**:
  1. 서울 열린데이터광장에서 Open API 인증키 발급
  2. `.env.example`을 참고해 `.env` 파일에 `SEOUL_OPEN_API_KEY=발급키` 입력
  3. `uv run python scripts/eda_analysis.py --source api`
- **배포 주소**: GitHub 저장소 설정에서 Pages 배포 후 확인 가능
