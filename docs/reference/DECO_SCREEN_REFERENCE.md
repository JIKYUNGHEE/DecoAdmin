# Deco 화면 참고 자료

## 홈 화면
- 사용자가 추천 코스 또는 공유된 코스를 탐색하는 화면
- Admin에서 선별한 추천 후보가 나중에 이 영역에 노출될 수 있음

## 코스 상세 화면
- 데이트 코스의 장소 순서, 설명, 태그를 보여주는 화면
- Admin에서 만든 태그와 추천 이유가 이 화면에 활용될 수 있음

## 코스 등록 화면
- 사용자가 직접 데이트 코스를 등록하는 화면
- 대표 코스가 등록되고, 장소가 하나씩 등록됨
- 향후 사용자 등록 코스 데이터가 추천 알고리즘에 활용될 수 있음

## 캘린더 화면
- 사용자가 등록한 코스가 날짜별로 캘린더에 표시되는 화면

## 지도 화면
- 코스에 포함된 장소를 지도에서 확인하는 화면
- Admin 데이터의 위치 정보가 향후 지도 연동에 활용될 수 있음
