# Deco 서비스 컨텍스트

## 1. Deco는 어떤 앱인가?
Deco는 커플이 데이트 코스를 기록하고 공유할 수 있는 모바일 앱이다.  
사용자는 자신이 다녀온 데이트 코스를 등록하고, 다른 사용자의 코스를 참고하거나 저장할 수 있다.

## 2. 핵심 사용자
- 데이트 코스를 고민하는 커플
- 새로운 장소나 코스를 찾고 싶은 사용자
- 자신이 다녀온 코스를 기록하고 공유하고 싶은 사용자

## 3. 핵심 기능
- 데이트 코스 등록
- 코스 상세 보기
- 장소 순서 구성
- 코스 공유
- 코스 저장/좋아요 기능 예정
- 지도 연동 예정

## 4. 현재 개발 상태
- Deco 앱은 개발 중이다.
- 지도 연동이 아직 남아 있다.
- 좋아요, 저장 등 사용자 반응 기능은 아직 구현 전이다.
- 아직 앱스토어/플레이스토어 배포 전이다.

## 5. Deco Admin이 필요한 이유
앱 출시 초기에는 사용자 등록 코스 데이터가 충분하지 않다.  
따라서 운영자가 서울시 문화행사·관광명소 데이터를 참고해 데이트 장소 후보를 선별하고, Deco 앱에 등록할 추천 코스나 장소 태그를 관리할 필요가 있다.

## 6. Deco Admin의 역할
Deco Admin은 일반 사용자가 보는 앱 화면이 아니라, 운영자가 보는 관리자용 대시보드다.

운영자는 Deco Admin에서 다음을 확인한다.
- 서울시 문화행사 현황
- 자치구별 행사 분포
- 카테고리별 행사 분포
- 주말 데이트 후보
- Deco용 추천 태그
- 앱에 등록할 만한 추천 후보 TOP 리스트

## 7. 향후 확장 방향
초기에는 공공데이터 기반으로 추천 후보를 선별한다.  
이후 Deco 앱에 실제 사용자 데이터가 쌓이면 다음 데이터를 활용해 추천을 고도화할 수 있다.

- 사용자 등록 코스
- 좋아요 수
- 저장 수
- 조회수
- 태그
- 지역 선호도
- 코스 완료/방문 여부
