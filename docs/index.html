추천 점수 산정 기준

이 추천은 머신러닝이 아니라 설명 가능한 규칙 기반 추천입니다.

  • 무료 여부와 가성비 태그를 반영합니다.
  • 종로구, 중구, 마포구 등 인기 지역 가중치를 반영합니다.
  • 전시, 공연, 체험, 야간 등 데이트 적합 태그를 반영합니다.
  • 지도 연동이 가능한 위치 정보 보유 여부를 반영합니다.
  • 행사 기간과 주말 시작 여부를 운영 관점에서 반영합니다.

전시관, 공연장, 광장, 공원 등 장소 단서를 활용해 보조 태그를 부여합니다.

Deco 앱 서비스 연결 구조

Admin에서 선별한 후보가 Deco 앱 사용자 경험으로 연결되는 흐름입니다.

1. 데이터 선별 → 앱 홈 추천

추천 후보 TOP 리스트는 Deco 앱 홈의 오늘의 추천 코스 영역으로 공급됩니다.

2. 태그 관리 → 검색 필터

무료, 전시, 체험, 야간 등 운영 태그는 앱 필터와 태그 클라우드로 확장됩니다.

3. 위치 정보 → 지도 연동

위도/경도 좌표는 앱 지도 핀, 이동 동선, 주변 장소 추천에 활용됩니다.

4. 추천 이유 → 상세 가이드

운영자 추천 이유는 코스 상세 페이지의 신뢰도 높은 설명 문구로 전환됩니다.

5. 사용자 반응 → 추천 고도화

향후 좋아요, 저장, 조회수, 방문 완료 데이터를 반영해 개인화 추천으로 확장합니다.
